# 💊 Medicine Tracker & Dose Reminder Android App

[![Platform: Android](https://img.shields.io/badge/Platform-Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)](https://developer.android.com/)
[![Language: Java](https://img.shields.io/badge/Language-Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)](https://java.com)

A native Android mobile application built to assist patients and caregivers in maintaining strict medicine schedules with automated reminders and prescription logging.

## ✨ Features
- ⏰ **Custom Dose Schedules:** Set morning, noon, and night medicine schedules with custom dosages.
- 🔔 **Timely Notification Alerts:** Trigger local notification reminders using Android AlarmManager even when the app is in the background.
- 🗄️ **Local Database Storage:** Offline-first architecture saving medicine names, stock counts, and history locally using SQLite.
- 📋 **Medicine Log History:** Review taken vs. missed doses over time.

## 🛠️ Tech Stack
- Java 11 / 17, Android SDK, SQLite, BroadcastReceiver, AlarmManager
